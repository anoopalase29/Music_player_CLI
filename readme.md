# 🎵 Terminal Music Player

A simple terminal-based music player built with JavaScript and Node.js. The application displays a list of songs and allows users to navigate between them using arrow keys. Users can play, pause, and resume songs, while a simulated progress bar shows the current playback time.

## Controls

* ↑ / ↓ — Navigate songs
* Enter — Play
* Space — Pause / Resume
* Q — Quit
